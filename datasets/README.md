# Datasets

This directory contains the four standardized point datasets used in the main experiments.

| File | Points | Size |
|---|---:|---:|
| `crime.txt` | 683,499 | 23.91 MB |
| `la_arrests_2010_2019_p001_p999_pad20.txt` | 1,319,142 | 38.28 MB |
| `t_drive_taxis.txt` | 3,201,688 | 76.33 MB |
| `sf_311_cases.txt` | 8,174,477 | 273.22 MB |

Each dataset is a plain-text two-dimensional point set in the standardized input format expected by the experiment scripts. See `summary.csv` for the compact metadata table.
